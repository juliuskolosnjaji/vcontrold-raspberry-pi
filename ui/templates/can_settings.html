CAN-Einstellungen

Konfiguriert config/can_mapping.json: Bitrate, eigene Knoten-Nummer und welche Werte auf welchen CAN-Slots gesendet bzw. empfangen werden. Die CAN-IDs sind erst nach dem CAN-Sniffer-Vorgehen (siehe README Abschnitt 3) bekannt — bis dahin einfach leer lassen.

Warum bei Analog alle 4 Slots eine neue CAN-ID: ein CAN-Frame hat hart maximal 8 Byte Nutzlast — bei 2 Byte pro Wert passen nur 4 Werte in einen Frame. Die {{ total_slots }} Analog-Slots verteilen sich deshalb auf {{ total_slots // 4 }} CAN-IDs (Slots 1-4, 5-8, 9-12, 13-16). Bei Digital passen alle {{ total_slots }} Bits in einen einzigen Frame, daher nur eine CAN-ID pro Spalte.

Senden-Slots: Freitextfeld mit Vorschlägen aus vito.xml-Variablen (siehe Variablen-Seite) — du kannst aber auch einen beliebigen anderen Namen eintragen, falls der Wert nicht aus vcontrold kommt (z.B. von Home Assistant direkt auf internal/can/tx/<name> published).

TA-Netzwerkausgänge (bestätigtes Schema)
