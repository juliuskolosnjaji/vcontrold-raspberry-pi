CAN-Einstellungen

Konfiguriert config/can_mapping.json: Bitrate, eigene Knoten-Nummer und welche Werte auf welchen CAN-IDs/Slots gesendet bzw. empfangen werden. Die CAN-IDs sind erst nach dem CAN-Sniffer-Vorgehen (siehe README Abschnitt 3) bekannt — bis dahin einfach leer lassen.

Warum max. 4 (bzw. 2 bei 4 Byte) Slots pro Block: ein CAN-Frame hat hart maximal 8 Byte Nutzlast — das ist eine physikalische Grenze des CAN-Protokolls, keine UI-Einschränkung. Für mehr Werte insgesamt einfach eine weitere Zeile mit eigener CAN-ID anlegen (bis zu {{ num_rows|length }} Zeilen pro Kategorie = bis zu {{ num_rows|length * 4 }} Analogwerte bzw. {{ num_rows|length * 16 }} Digitalwerte).
