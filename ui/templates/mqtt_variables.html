MQTT-Variablen

Zentrale Definition aller MQTT-Variablen: Anzeigename in Home Assistant + ob/wie eine Variable per MQTT setzbar ist. Unabhängig davon, ob der Wert aus vito.xml (Vcontrold) oder direkt von CAN stammt -- weder Bestandteil der Vcontrold- noch der CAN-Einstellungen-Seite. Welchem Lese-Zyklus eine vito.xml-Variable zugeordnet ist, bleibt auf der Vcontrold-Seite; welche CAN-ID/welcher Sendekanal eine Variable nutzt, bleibt auf der CAN-Einstellungen-Seite.

vito.xml-Variablen

Erscheint automatisch, sobald vito.xml einen Getter dafür hat. "Anzeigename" ändert nur den in Home Assistant angezeigten Namen (leer = automatisch aus dem Variablennamen abgeleitet), getTempKsoll/setTempKsoll bleiben unverändert. "Schreibbar" ist nur wählbar, wenn vito.xml einen Setter hat -- macht die Variable per heizung/cmd/<Name> setzbar (Home Assistant und/oder CAN-Weiterleitung).
